html-anime

Films drawn entirely in code by a crew of agent skills. Pick one below, or write the next scene: the sheet locks the shots, the holds, and the colors, and Claude, Codex, Cursor, or Grok draw it as HTML and three.js.

The sheet runs in the browser. If this note is still here, serve the folder and open the address it prints: python -m http.server

Skills

        
A studio crew, one skill per role. The director runs them in order. Each one owns a single job.

        

          
            

              Director
              Refines the brief, builds the sheet or a sequence of sheets, holds the gates, signs off.
            

            

              Designer
              An original character gets a model sheet example to approve first. A reference is followed exactly.
            

            

              Art
              The style to follow, the color roles, the value plan, the backgrounds.
            

            

              Motion
              Key poses, grips, pivots, and frame counts for blades, strikes, running, tools, cloth, and effects.
            

            

              Cameraman
              Size, angle, lens feel, where the eyes sit, and the one move a shot may have.
            

            

              Staff
              Layout, keys, inbetweens, correction against the model sheet, finishing. Paints by cel, times by timing.
            

            

              Voice
              Casts a voice per character, in any language, with emotion. Generates the audio and the mouth track.
            

            

              Render
              The HyperFrames file. A color dip is the cut. The checks have to pass. 24 fps.
